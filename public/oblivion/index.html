      What this experiment proves

      A complete folder can require several gigabytes of temporary memory. Use a desktop for full-install tests. Local browser saves from this experiment are temporary.

      A Wine loader error identifies missing DLLs or runtime requirements. Starting a process does not establish working menus, graphics, sound, saves, or gameplay. Large installations are not loaded lazily; use a desktop for larger experiments.

      This preset targets original Steam Oblivion 1.2.0416. Remastered uses a different engine and cannot use it. Game files and Steam client services are not included. Steam builds can require a running signed-in client that this browser runtime does not provide. Application load error 5:0000065434 has been reported with this installation; its Steam startup requirement is unresolved here.
